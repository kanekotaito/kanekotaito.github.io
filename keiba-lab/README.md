# KEIBA LAB | 競馬予想研究所

**公開用の静的Webアプリ**。React・サーバー・APIキー不要。GitHub Pagesの `/keiba-lab/` 以下で動き、既存サイトのトップは変更しません。

## 何ができるか

- 12レースの**完全架空**サンプル（結果がある10レース、未確定2レース）
- 近走・展開・競馬場・距離・馬場・血統・騎手・厩舎・調教・枠順・斤量・クラス・間隔・オッズ市場評価、14の項目を調整
- softmaxによるモデル内勝率、モンテカルロによる3着内確率・期待着順、単勝オッズとの比較
- 総合/近走/血統/展開/市場/カスタムの仮説を比較し、Log Loss・Brier・的中率・仮想回収率を見る
- 予想時の確率・設定・オッズのスナップショット、予想メモ、結果発表後の答え合わせ
- JSON/CSVのローカル取込、過去走からの簡易スコア算出、バックアップ
- iPhone/PC対応ダークUI。外部アカウント不要

## 使い方

1. `index.html` を開く（またはGitHub Pagesの公開URL）。
2. デモのレースを選んで、予想モデルを比較。
3. 右側の重みを動かして「この予想を記録」。
4. 結果が登録されていれば「結果を表示」で答え合わせ。
5. 「手法を比較」で仮説間の差を確認。
6. 実際の出走データを**適法な方法で準備**し、JSONまたはCSVで取り込む。

## 注意

**このバージョンは完成した実戦予測AIではなく、研究用の動くプロトタイプです。** 公式の当日データを自動取得したり、正式な学習済み予測モデルで勝率を校正したりしていません。初期レース・出走馬・結果は全て架空です。手元の実データでアウトオブサンプル検証してから実戦価値を判断してください。

データ形式、過去走の必要項目、リーク防止、ライセンスの説明は [DATA_FORMAT.md](./DATA_FORMAT.md) にあります。

## ソースコード

- `index.html`: UIのHTML
- `styles.css`: レスポンシブUI
- `feature-engine.js`: 過去走から事前特徴量の簡易生成
- `app.js`: 予測計算・モデル比較・取込・保存・評価
- `tests/smoke.test.cjs`: Node.jsによる基本テスト

### 開発時

```bash
node keiba-lab/tests/smoke.test.cjs
```

GitHub Pagesでの表示は `https://kanekotaito.github.io/keiba-lab/` を想定。Pagesがリポジトリのmainブランチから配信されている必要があります。
