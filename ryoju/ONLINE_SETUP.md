# 猟銃考査 マッチョ育成：オンライン道場の接続設定

GitHub Pages は誰でも開けますが、異なるスマホ間で対戦するには **Supabase データベースの初期設定**が必要です。未接続時はアプリ画面に「接続の準備中」と表示します。

## Supabase 初期設定

1. このゲーム専用の Supabase プロジェクトを作成
2. Authentication → Providers で **Anonymous Sign-Ins** を有効化
3. Supabase SQL Editor で [online-schema.sql](./online-schema.sql) を実行
4. Project URL と **publishable key**（旧 anon key でも可）を [online-config.js](./online-config.js) に設定。service_role / secret キーは絶対に書かない
5. GitHub Pages で /ryoju/?v=16 を開き、オンライン道場から「公開登録する」
6. 別のスマホも同じ URL から参加し、公開一覧から相手を選んで対戦

## プライバシーと学習データ

- ブラウザー内：600問の回答、学習履歴、コイン、購入済み問題と詳細な試験結果
- オンライン公開：本人が許可した名前、習得問題数、クリアパック、模試最高点、復習克服数、筋肉レベルだけ
- オンライン対戦は**非同期**です。相手がその場でアプリを開いていなくても、最後に公開した成績と腕相撲できます
- 自己申告した成績の改ざんは完全には防げません。公認のランキング、賭け事、金銭報酬には使用しません

## 所有権と削除

公開情報は Supabase Auth の匿名ユーザーにひも付け、Row Level Security で**自分の公開データしか更新・削除できない**ようにします。名前の横の「✕」でプレイヤー削除、入力確認を行います。オンライン公開中ならクラウド側を削除してからローカルデータを削除。クラウドの削除が失敗した場合はローカルデータを保護します。

**匿名アカウントの注意点**：ブラウザーのデータを消すと、そのオンラインプロフィールの更新・削除権限を復元できなくなることがあります。機種変更には学習記録のバックアップを取ってください。ただし JSON バックアップだけで Supabase 匿名認証は復元できません。長期運用する場合はメール認証などの導入を検討してください。

「タイト」の既存記録は削除操作をしない限り引き継ぎます。最後のプレイヤーを削除した場合は空の「ゲスト」を作成します。
