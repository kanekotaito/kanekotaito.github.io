# みんなの筋肉道場 Ver.17：無限進化

## 学習データ
- 既存のSafari/localStorageの全プレイヤーと「タイト」の学習記録はそのまま。保存データの削除や書き換えは不要。
- 新規習得1問＝筋肉パワー+1、パック完全クリア＝+25、累計正解2回＝+1。正解を繰り返しても育つ。
- Lv.16以降は超大型・多腕・翼獣・異次元の生命体へ進化。レベル数は固定の上限を設けない。
- 回転・なでる操作・成長比較・模試・復習・ローカル腕相撲は継続する。対戦でコインや学習成果は減らない。

## 新問題の追加
1. ryoju/question-updates.js の window.RYOJU_ADDITIONAL_QUESTIONS に問題を追加する。
2. 現行の問題ID 1～600は変更しない。新しいIDは601から連番にする。既存の保存形式がIDをキーにしているため、旧IDの使い回しや欠番は避ける。
3. 追加問題は id、q、a（○または×）、why、topic、section、kind、pack を持たせる。
4. 9パック目以降は pack=9,10,11... とし、50問単位を原則とする。古い購入記録は変えない。
5. 問題文・正解・解説は更新前に最新版の法令や公的出典と照合する。現時点では追加問題は空なので、引き続き600問。

## オンライン対戦の導入
- 別端末との対戦にはSupabase URL・公開鍵・Anonymous Sign-Inの設定が別途必要。GitHub Pages公開だけでは対戦相手は自動で共有されない。
- 古いオンライン表がある場合は ryoju/online-v17-migration.sql をSupabase SQL Editorで実行する。新規環境では更新済みの ryoju/online-schema.sql を利用。
- 既存のオンラインレコードを削除せず、累計正解数列と無上限の筋肉レベルを追加する。
- 公開対象はオプトインしたプレイヤー名と対戦用の集計値のみ。個々の回答・学習履歴は公開しない。

## 確認項目
- タイトの記録が残る・新しい人の学習記録が分離される。
- 繰り返し正解で累計正解数・パワー・進化ゲージが増える。
- 600問以降を追加しても9番以降の問題・パックが出現する。
- スマートフォンとPCで異形人形・回転・対戦画面が破綻しない。
- Safariのデータ削除に備え、学習記録室からバックアップする。
